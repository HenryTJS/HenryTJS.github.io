# 趣味数学（funmath）

个人主页的趣味数学栏目：**一类一篇**，每篇包含知识介绍 + 代码实现 + 复杂度分析 + 挑战题。
阅读体验参考飞书文档：左侧目录树、中间正文、右侧大纲、顶部阅读进度。

## 目录结构

```
funmath/
├── index.html                 # 栏目入口：直接跳转到默认文档 prime
├── css/style.css
├── js/script.js               # 读取 json/data.json 渲染目录
├── json/
│   └── data.json              # ⭐ 唯一的「目录数据源」：分区 → 分类 → 篇目
└── template/
    ├── index.html             # 文档页：?id=prime 这样的形式访问
    ├── css/style.css
    ├── js/script.js           # 目录树 / 大纲 / 滚动高亮 / 复制代码 / 提示块 / KaTeX
    └── md/                    # ⭐ 正文 Markdown 文件，文件名与 data.json 的 id 一致
        ├── _template.md       # 写作模板（不会出现在目录里）
        ├── prime.md
        ├── perfect.md
        ├── amicable.md
        ├── magic-square.md
        └── sudoku.md
```

> 依赖：Markdown 解析用的是 `article/template/js/marked.min.js`（复用已有文件）。
> 如果希望本栏目完全自包含，把该文件复制到 `funmath/template/js/` 并改 `index.html` 里的路径即可。

## 如何新增一篇

访问 `/funmath/` 会直接打开默认的「素数」文档；所有篇目通过文档页左侧目录树切换，不再经过单独的卡片目录首页。

1. **写正文**：复制 `template/md/_template.md`，重命名为 `新篇目id.md`，按模板小节写内容。
2. **登记目录**：在 `json/data.json` 里找到对应的分类（`groups`），往 `articles` 数组加一项：

   ```json
   {
     "id": "新篇目id",
     "title": "显示用的标题（纯文本，不要写 LaTeX）",
     "summary": "一到两句话的摘要，会显示在卡片上",
     "level": "入门",
     "tags": ["标签1", "标签2"],
     "date": "2026-09-10",
     "status": "ready"
   }
   ```

   - `status` 为 `"ready"` 时目录树可点击、卡片显示「已更新」；
   - 为 `"planned"` 时显示为虚线卡片与「待写」标记，点进去是一张写作计划占位页。
   - 还没写但已规划好的篇目，建议先以 `planned` 登记，这样整个栏目是一张实时更新的路线图。

3. **完成**。左侧目录树、上下篇导航、右侧大纲都会自动生成，不需要改代码。

## Markdown 支持的扩展语法

**提示块**（四种类别：`NOTE` / `TIP` / `WARN` / `IMPORTANT`）：

```markdown
> [!TIP] 小标题
> 这里是提示内容，支持 **加粗**、列表、公式。
```

**数学公式**：行内用 `$...$`，独立成行用 `$$...$$`，由 KaTeX 渲染。
解析前会先对公式做占位保护，因此 `$a_i \cdot b_i$` 这类含有多个下划线的公式不会被打成斜体。

**表格 / 代码块**：标准写法。代码块会自动加上语言标签与一键复制按钮。

## 后续可提升的点

- **代码可运行化**：接入 Pyodide（本地或 CDN），让 Python 代码块支持「在线运行」。注意 `file://` 下无法加载，需要本地服务器或部署后使用。
- **代码高亮**：目前代码块是统一配色；可引入 highlight.js 的 Python 主题。
- **公式渲染时机**：KaTeX 目前走 CDN，若要完全离线，可把 katex 的 `dist` 目录下载到 `libs/` 下引用。
- **全站样式统一**：`funmath/css/style.css` 与 `article/css/style.css` 的变量是重复的，后续可抽一份公共 `css/base.css`。
